# Instructions for AgriPickup Operational & Deployment Scripts

This directory houses administrative, setup, and maintenance scripts for the AgriPickup full-stack agricultural marketplace platform.

### Common Tasks
- **Database Seeding & Migration**: Handled via backend scripts (`npm run prisma:seed`, `npx prisma migrate dev`).
- **Dev Servers**: Use `npm run dev:frontend` and `npm run dev:backend` from the project root.
